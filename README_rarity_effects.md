# 图片稀有度效果添加工具

这个工具可以为不同稀有度的图片添加自然且具有高级感的额外效果，如粒子效果、闪箔效果等。

## 功能特点

- 支持5种稀有度等级：普通(Common)、罕见(Uncommon)、稀有(Rare)、史诗(Epic)、传奇(Legendary)
- 每种稀有度都有独特的视觉效果组合，效果更加自然和平衡：
  - 普通：柔和微光效果
  - 罕见：青色发光和适量粒子
  - 稀有：蓝色发光、粒子和适度闪箔效果
  - 史诗：紫色发光、粒子、闪箔和适量闪烁效果
  - 传奇：金色发光、粒子、闪箔、闪烁和柔和光环效果
- 多层次发光效果，更加自然柔和
- 智能分布的粒子效果，与背景更和谐
- 多彩闪箔效果，根据稀有度自动调整颜色
- 多形状闪烁效果，包括星形、菱形和光点
- 多层次光环效果，带有细腻的渐变过渡
- 可选禁用发光效果或光环效果以获得不同的视觉效果

## 使用方法

1. 确保安装了必要的Python库：
   ```
   pip install Pillow numpy
   ```

2. 将需要处理的图片放在 `output_acrylic_text_with_icons` 文件夹中

3. 编辑 `rarity_mapping.json` 文件，为每张图片设置对应的稀有度：
   ```json
   {
     "image1.png": "common",
     "image2.png": "uncommon",
     "image3.png": "rare",
     "image4.png": "epic",
     "image5.png": "legendary"
   }
   ```

4. 运行脚本：
   ```
   # 启用所有效果（包括发光和光环效果）
   python add_rarity_effects.py
   
   # 禁用发光效果，保留其他所有效果
   python add_rarity_effects.py --no-glow
   
   # 禁用光环效果，保留其他所有效果
   python add_rarity_effects.py --no-aura
   
   # 同时禁用发光和光环效果，只保留粒子、闪箔和闪烁效果
   python add_rarity_effects.py --no-glow --no-aura
   ```

5. 处理后的图片将保存在以下文件夹中：
   - 启用所有效果：`output_rarity_effects` 
   - 禁用发光效果：`output_rarity_effects_no_glow`
   - 禁用光环效果：`output_rarity_effects_no_aura`
   - 同时禁用发光和光环效果：`output_rarity_effects_no_glow_no_aura`

## 稀有度配置说明

- **普通(Common)**: 白色柔和微光效果，非常subtle
- **罕见(Uncommon)**: 青色发光和适量粒子效果
- **稀有(Rare)**: 蓝色发光、粒子和适度闪箔效果
- **史诗(Epic)**: 紫色发光、粒子、闪箔和适量闪烁效果
- **传奇(Legendary)**: 金色发光、粒子、闪箔、闪烁和柔和光环效果

## 优化说明

最新版本对效果进行了以下优化：

1. **发光效果优化**：
   - 使用多层次发光技术，创建更柔和自然的发光效果
   - 增加了发光区域的随机偏移，使发光更加不规则和自然
   - 调整了发光颜色的透明度，使其与背景更和谐

2. **粒子效果优化**：
   - 改进了粒子分布算法，使粒子更自然地分布在图片周围
   - 根据粒子位置调整透明度，边缘粒子更透明
   - 增加了粒子形状的多样性

3. **闪箔效果优化**：
   - 根据稀有度自动调整闪箔颜色，不只是金色
   - 改进了闪箔分布，使其更自然地融入背景
   - 优化了闪箔透明度，使其不过于突兀

4. **闪烁效果优化**：
   - 增加了闪烁形状的多样性，包括星形、菱形和光点
   - 根据位置调整闪烁透明度
   - 减少了闪烁数量以避免过于密集

5. **光环效果优化**：
   - 使用多层次光环技术，创建更柔和的光环效果
   - 增加了光环的渐变过渡效果
   - 优化了光环颜色和透明度

## 自定义配置

可以在 `add_rarity_effects.py` 文件中修改 `RARITY_CONFIG` 来调整每种稀有度的效果参数。
